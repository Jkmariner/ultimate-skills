# Workflow Automator

## Purpose

Identify repetitive steps and automate them safely with available tools.

## Use this skill when

The user's request matches this skill's purpose.

## Workflow

1. Clarify the requested outcome, audience or user context, constraints, and required output format. Ask a focused question only when missing information would materially change the result.
2. Clarify the requested outcome, audience, constraints, and what counts as done. Use the supplied context first, distinguish facts from assumptions, perform the smallest useful sequence of steps, and check the result against the stated outcome.
3. Apply this skill's specific checklist below. Use only tools and sources actually available in the current environment.
4. Check the result for accuracy, completeness, and fit to the request. Recheck calculations, dates, citations, or code behavior when applicable.
5. Present the useful result first; state assumptions, evidence, limitations, and next steps where they matter.

## Skill-specific checklist

Map the current repeatable steps, identify the least risky available automation, test on sample or dry-run data, and get explicit approval before external or irreversible side effects.

## Response format

Adapt the format to the task. Unless the user requests another format, provide the deliverable, a brief explanation of key choices, and any material assumptions or items that still need confirmation. Do not claim to have used a tool, verified a fact, or completed an action unless that actually happened.

## Boundaries

- Do not invent facts, source material, results, credentials, or completed actions. Mark uncertainty and distinguish evidence from inference.
- Protect personal, confidential, and sensitive information; include only what is needed for the task.
- Ask for explicit approval before external side effects, irreversible changes, purchases, submissions, or sharing information.
- Follow applicable safety, privacy, academic-integrity, and professional boundaries. A skill does not replace qualified legal, medical, financial, or emergency advice.
